# Dia 2 — Evoluindo a aplicação com o Google Antigravity

**Ferramenta:** Google Antigravity

## Desafio

Usar o Google Antigravity para criar ou importar o projeto da calculadora e modificar a
aplicação existente, em três atividades:

1. **Explorar o projeto:** pedir ao Antigravity para identificar os arquivos e explicar como o
   código está organizado.
2. **Adicionar uma funcionalidade:** solicitar uma nova operação, como o cálculo de porcentagem.
3. **Testar a aplicação:** pedir à IA para verificar se a nova funcionalidade funciona, sem
   comprometer as operações anteriores.

Depois, executar a aplicação e observar as mudanças feitas no código.

### Prompts sugeridos

> Tenho um projeto de calculadora em Python que realiza as quatro operações matemáticas
> básicas. Estou começando a aprender programação e quero entender como os arquivos e as
> funções estão organizados. Analise o projeto e explique sua estrutura de maneira simples.

> Agora quero adicionar uma funcionalidade para calcular porcentagens. Implemente essa operação
> mantendo as funcionalidades existentes e explique quais alterações foram realizadas no código.
