# Dia 1 — Criando sua primeira aplicação com IA

**Ferramenta:** Google AI Studio

## Desafio

Usar o Google AI Studio para gerar uma calculadora em Python com as quatro operações básicas
(adição, subtração, multiplicação e divisão) e entender como a aplicação funciona.

O objetivo não é dominar Python de imediato, e sim começar a compreender como instruções,
variáveis e condições são utilizadas na construção de um software.

### Prompt sugerido

> Quero criar uma calculadora simples em Python que realize as quatro operações matemáticas
> básicas. Estou começando a aprender programação, então gere um código simples e organizado,
> com explicações sobre seus principais componentes.

Depois de gerar, continuar conversando com a IA: pedir para explicar uma parte do código,
identificar as variáveis utilizadas ou mostrar como a aplicação decide qual operação executar.
