# Imersão IA — Alura

Registro dos desafios da imersão de IA da Alura, com foco nas ferramentas de IA do Google:
**Google AI Studio** e **Google Antigravity**.

O projeto central é uma calculadora em Python. Ela nasce no AI Studio (dia 1) e evolui no
Antigravity nos dias seguintes. O código é gerado pelas IAs; as anotações registram o que
aprendi sobre ele.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| [`calculadora/`](calculadora/) | O projeto da calculadora |
| [`anotacoes/`](anotacoes/) | Enunciado de cada desafio e minhas respostas |

## Desafios

- [Dia 1 — Criando sua primeira aplicação com IA](anotacoes/dia1.md) (Google AI Studio)
- [Dia 2 — Evoluindo a aplicação com o Google Antigravity](anotacoes/dia2.md)
- [Dia 3](anotacoes/dia3.md)

## Como rodar

Requer Python 3.11 ou mais recente.

```bash
python3.11 -m venv .venv      # só na primeira vez
source .venv/bin/activate
python calculadora/<arquivo>.py
```
